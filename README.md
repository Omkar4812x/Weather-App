# ☀️ SkyPulse Pro - Live Weather Dashboard & Forecast Studio

> **Real-time global weather dashboard with 24-hour hourly timelines, 5-day extended forecasts, Air Quality Index (AQI), dual-engine API fallback, and animated particle backdrops.**

---

## ✨ Key Features

- 🌤️ **Dual Weather Engine Support**
  - **Open-Meteo API**: Works out-of-the-box with zero API key configuration required!
  - **OpenWeatherMap API**: Optional custom API key integration.

- ⏱️ **24-Hour Timeline & 5-Day Extended Forecast**
  - Scrollable hourly timeline tracking temperature trends and weather conditions throughout the day.
  - 5-Day daily forecast breakdown with high/low temperatures and weather icon badges.

- 🌬️ **Air Quality & Health Index (AQI)**
  - Real-time monitoring of PM2.5, PM10, NO2, SO2, and O3 pollutants with health advisory cards.

- 📊 **Detailed Weather Metrics Grid**
  - Instant readings for **Humidity**, **Wind Speed & Direction**, **Barometric Air Pressure**, **UV Index**, and **Visibility**.

- 🔍 **Global City Search & Geolocation**
  - Smart autocomplete search for cities worldwide.
  - One-click Geolocation detection (`Ctrl+M`) for instant local weather.
  - Saved Favorite Cities list stored in LocalStorage.

- 🌡️ **Interactive Unit Conversion & Themes**
  - Instant temperature conversion between Celsius (°C) and Fahrenheit (°F).
  - Light and Dark mode themes with animated weather canvas background particles.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3 (Glassmorphism, Flexbox/Grid)
- **API Engines**: Open-Meteo API & OpenWeatherMap API
- **Icons & Graphics**: FontAwesome 6, HTML5 Canvas Particle Engine
